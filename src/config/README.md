# Web Server 启动配置库
************************
## 特性
### 分层配置
按优先级从低到高，依次读取：
* 代码中的默认值。用于所有配置均失效时的兜底策略。
* 当前目录下的`config.toml`文件。
* 根据环境变量自动选择`profile`。
* 当前以`APP_`开头的环境变量。变量名小写与`config.toml`名字一致。(变量名分层之间映射为为双下划线)
* 启动时的命令行参数。参数名与`config.toml`一致，除了命令行参数的连字符在`config.toml`中为下划线。
### 热加载
配置采取热加载，可通过多种方式修改配置，而不必重启程序。
* 修改`config.toml`中的配置项时，程序自动监控配置变化，重新载入配置。
### 单例模式
配置采取单例模式，同一个二进制文件使用的单例是固定的。
* 采取`OnceLock<RwLock<Config>>`实现单例
